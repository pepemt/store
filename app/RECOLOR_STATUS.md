## 🔧 **Cómo Cambiar Colores**

### Para cambios rápidos:
Edita las variables en `src/styles/colors.css`:

```css
:root {
  --color-primary: #C344AB;    /* Tu rosa principal */
  --color-secondary: #85E3FF;  /* Tu azul cielo */
  --color-accent-pink: #FFD7F7; /* Rosa pastel */
  --color-accent-blue: #D9F7FF; /* Azul claro */
  --color-background: #F9FAFC;  /* Fondo gris */
  --color-white: #FFFFFF;       /* Blanco */
}
```
